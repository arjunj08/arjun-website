# Arjun Jammalmadaka's Premium Developer Portfolio

This is a premium, custom-designed developer portfolio built with React 18, Vite, TypeScript, TailwindCSS, GSAP, and Three.js (React Three Fiber).

## Setup Instructions

1.  **Resume File**:
    *   Place your actual resume PDF in the `public/` directory and name it exactly `resume.pdf`.
    *   This enables the "Download Resume" buttons in the hero section and contact section to download the file correctly.

2.  **Project Media Assets**:
    *   Place your actual high-quality mockups, loop recordings, or screenshots in the `public/images/projects/` directory.
    *   Name them exactly:
        *   `selfcall.webp` (or `.mp4` loop video)
        *   `dayzero.webp`
        *   `skillbridge.webp`
        *   `gridpulse.webp`
        *   `eventsync.webp`
        *   `edusphere.webp`

3.  **Local Development**:
    ```bash
    npm run dev
    ```

4.  **Production Build**:
    ```bash
    npm run build
    ```
